# Official Microsoft Azure architecture icons

These SVGs are copied without modification from Microsoft's **Azure Public Service Icons V24**
package, downloaded from the Azure Architecture Center on 3 September 2026.

- Source page: https://learn.microsoft.com/en-us/azure/architecture/icons/
- Package: https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V24.zip
- Package update noted by Microsoft: July 2026

Microsoft permits these icons in architecture diagrams, training materials, and documentation.
The source guidelines require preserving the artwork: do not crop, flip, rotate, recolor, distort,
or use an Azure product icon to represent a custom product.

Only icons used by the approved customer figures are retained here. Service names remain adjacent to
the icons in every render.
